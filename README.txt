CHUNKS STEAK BOX — WEBSITE FILES

WHAT'S INCLUDED
- index.html: the complete responsive website
- images/: your food photos used on the website

PREVIEW
1. Extract the ZIP file.
2. Open index.html in a browser.
3. The site uses local images in the images folder, so keep that folder alongside index.html.

BEFORE SHARING
- The website shows the hours you confirmed: Sunday–Thursday 4 pm–midnight; Friday–Saturday 4 pm–1 am.
- Collection only is shown, with delivery coming soon.
- Phone ordering: 01706 560049.
- It mentions parking at the front and rear and the bring-to-car service.
- The location link searches for Chunks Steak Box on Halifax Road, Rochdale. Check the exact address/pin before publishing.
- Pizza sizes are listed as 9-inch and 12-inch only. The pizza prices in the photo are a little hard to read, so please double-check them before relying on those prices.
- Review all menu prices and allergen information before publishing. This is a website display, not an online checkout.

PUBLISH FREE WITH GITHUB PAGES
1. Go to https://github.com/ and create/sign in to a free account.
2. Create a new public repository named chunks-steak-box.
3. Upload index.html and the entire images folder (keep the same file names).
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for the published link to appear in Settings → Pages. It will usually look like https://YOUR-USERNAME.github.io/chunks-steak-box/
7. Open the live link on a phone and computer to test it.

You do not need to buy a domain or pay to host this simple site. A custom domain is optional and usually costs money.
